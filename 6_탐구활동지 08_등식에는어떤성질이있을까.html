핵심 개념 도움말

등식에는 어떤 성질이 있을까

저울로 보는 등식의 성질

양쪽에 똑같이 하면 균형은 깨지지 않는다

성질 ① 더하기
a = b 이면 a + c = b + c
양쪽 접시에 같은 추를 올린다.

성질 ② 빼기
a = b 이면 a − c = b − c
양쪽 접시에서 같은 추를 내린다.

성질 ③ 곱하기
a = b 이면 ac = bc
양쪽을 똑같이 몇 배로 늘린다.

성질 ④ 나누기
a = b 이고 c ≠ 0 이면 a/c = b/c
양쪽을 똑같이 몇 등분한다.
단, 0으로는 나눌 수 없다!

💡 핵심은 '양쪽에 똑같이'이다. 한쪽에만 무언가를 하면 저울은 곧바로 기운다.

성질로 방정식 풀기

x만 홀로 남길 때까지 양쪽을 똑같이

목표
x = (수) 꼴로 만들기
x 옆의 것들을 하나씩 걷어 낸다.

예) x + 3 = 7
양변에서 3을 뺀다 (성질 ②)
x + 3 − 3 = 7 − 3
x = 4

예) 2x = 10
양변을 2로 나눈다 (성질 ④)
2x ÷ 2 = 10 ÷ 2
x = 5

예) 3x − 1 = 8
양변에 1을 더한다 → 3x = 9
양변을 3으로 나눈다 → x = 3
