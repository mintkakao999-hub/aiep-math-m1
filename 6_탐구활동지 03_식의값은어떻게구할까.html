핵심 개념 도움말

식의 값은 어떻게 구할까

대입과 식의 값

생략된 × 를 되살리고 → 괄호로 넣고 → 계산한다

1단계 · 기호 되살리기
3a → 3 × a
a² → a × a

2단계 · 괄호로 대입
a = 4 일 때 3 × (4)
a = −2 일 때 3 × (−2)

3단계 · 계산하기
3 × (4) = 12
3 × (−2) = −6

예) a = −3 일 때 a² 의 값
a² = a × a = (−3) × (−3) = 9
괄호를 빠뜨려 −3×3 = −9 로 계산하지 않도록 주의!

💡 대입은 '자리 바꾸기'다. 문자가 있던 자리에 수를 통째로(괄호째) 넣는다고 생각하자.

실수가 나오는 자리

음수·분수·거듭제곱에서 가장 많이 틀린다

음수 대입
x = −2 일 때 −x = −(−2) = 2
−x 는 항상 음수가 아니다!

거듭제곱
x = −2 일 때 x² = (−2)² = 4
−x² = −(−2)² = −4 ( 부호 위치에 주의 )

분수 대입
x = 1/2 일 때 2x = 2 × (1/2) = 1
1/x = 1 ÷ (1/2) = 2

두 문자 대입
a = 2, b = −1 일 때 3a − 2b
= 3×(2) − 2×(−1) = 6 + 2 = 8

💡 대입할 때 괄호를 먼저 치고 수를 넣는 습관을 들이면 부호 실수의 대부분이 사라진다.
